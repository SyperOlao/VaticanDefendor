# План завершения сетевого backend

Дата: 2026-11-05. Область: существующие Unity 6000.6.6f1 / Netcode for Entities 6.6.0 и FastAPI / PostgreSQL. Целевые клиенты — Android и iOS. После уточнения пользователь выбрал логин/пароль вместо Google/Apple; награды и покупки за игровую валюту, каталог из серверного конфига без выдуманных товаров и цен. Реальные платежи не входят в этот этап.

Существующие сцены, конфиги и незакоммиченные пользовательские изменения сохраняются. Игровая симуляция остаётся в Unity Dedicated Server, постоянный профиль и кошелёк — в backend. Миграции добавляются поверх существующих; повтор награды или покупки не меняет баланс второй раз.

## Этапы и критерии приёмки

| Этап | Изменение | Проверка | Статус |
| --- | --- | --- | --- |

| 2 | Ограниченный пул PostgreSQL, неблокирующий запрос назначения и клиентский bootstrap с отменой | Нет ожидания сети на главном потоке; назначения не дублируются; отмена/ошибка корректно освобождает ресурсы | implemented; см. проверки ниже |
| 3 | Логин/пароль, привязка гостя, одноразовый код восстановления, короткая access-сессия и ротация refresh-токена | Пароль хранится как Argon2id-хеш; логин уникален; восстановление отзывает старые сессии; повтор refresh не создаёт вторую сессию | implemented; см. проверки ниже |

| 6 | Интеграционные проверки и инструкции запуска | Миграции на отдельной БД, существующие и новые тесты, доступные Unity compile/build проверки; ограничения отмечены явно | частично проверено; ограничения среды ниже |

## Внешняя конфигурация

- Google/Apple отложены по уточнению пользователя. Пароли и токены не записываются в репозиторий/логи; мобильный клиент не сохраняет их в PlayerPrefs.
- Для удалённого транспорта нужны сертификат сервера, приватный ключ и доверенный клиентом CA; для API — HTTPS endpoint.
- Предметы и цены задаются продуктовым каталогом; неподтверждённый баланс не включается как рабочая политика.
- Локальные проверки используют отдельную disposable PostgreSQL БД и тестовые ключи. Продуктовые данные не очищаются.

## Результаты

Внедрены этапы 1–5. Этап 6 выполнен в доступной локальной среде, с указанными ниже ограничениями. Инструкция конфигурации и запуска: [ONLINE_BACKEND_RUN.md](ONLINE_BACKEND_RUN.md).

- Python 3.12, отдельный локальный PostgreSQL 15: **19 тестов прошли**. В том числе исходные 7 и новые проверки аккаунтов, ротации и конкуренции с восстановлением, покупок, receipt, каталога, авторизации и async assignment. Docker daemon недоступен; PostgreSQL 16 из CI локально не запускался.
- Unity 6000.6.6f1: импорт и компиляция C# успешны. `OnlineBackendVerification.Verify`: текущий ContentRelease сохраняет канонический ID после JSON roundtrip; изменение баланса отклоняется; удалённый plaintext endpoint отклоняется.
- `OnlineTransportVerification.Verify`: реальная пара Unity Transport драйверов передала payload через DTLS с локальным тестовым сертификатом; неверное имя сертификата не установило соединение. Это проверка транспорта на localhost, не WAN-нагрузка.
- `OnlineBackendVerification.VerifyApiClient`: реальный C# `BackendAccountClient` зарегистрировал тестовый аккаунт в отдельном API/PostgreSQL, прочитал профиль, каталог, инвентарь, вышел и вошёл вновь; отозванный access получил 401.
- macOS Development Client собран. В отдельном процессе визуально проверен экран входа 450×800; найденная ошибка начального World исправлена и проверена повторным запуском. Автоматизация кликов вернула `noWindowsAvailable`, поэтому ручной полный UI flow не объявляется проверенным.
- Mac Dedicated Server build предпринят, но завершился ошибкой окружения: `Dedicated Server support for MacStandalone is not installed`. В установленном Editor доступны только Mac player modules; Android/iOS сборки и устройства не проверены.

## Оставшиеся проверки и настройки

1. Установить Dedicated Server и Android/iOS build support, выполнить dedicated/mobile сборки, сквозной запуск аккаунт → назначение → DTLS → игра → награда и touch/keyboard UI на устройствах.
2. Задать реальные HTTPS endpoint, публичный адрес игрового сервера, сертификат/ключ и доверенный CA. Внешняя публикация и Caddy ACME не выполнялись: домен и deployment не предоставлены.
3. Создать `Resources/NetworkDeployment.asset` с endpoint и публичным CA для телефонов. В рабочем каталоге нет выдуманных товаров/цен: заполнить `backend/shop-catalog.json`, меняя version при каждом изменении.
4. Новые покупки выдают записи инвентаря. Игровые эффекты конкретных предметов требуют утверждённых правил; реальные платежи отсутствуют.
5. Вход после перезапуска приложения повторный: credentials хранятся только в памяти. Потерянный ответ на refresh требует повторного входа; уже открытый UDP-сеанс не отключается автоматически при восстановлении пароля. Незавершённая покупка сохраняет operation ID без credentials и восстанавливается через receipt.
6. Один процесс на забег сохранён. Продолжительный soak, fleet/autoscaling, WAN-нагрузка и мобильная производительность не проверялись.

Изменения пользователя в материалах, настройках рендера и MergedVersion.html сохранены. Тестовая БД создана отдельно; продуктовые миграции/данные не трогались.

Логи локальных проверок сохранены в игнорируемом `Builds/OnlineMac/Verification/`; окончательная клиентская сборка — `Builds/OnlineMac/Client/VaticanDefendor.app`. Локальные тестовые API, клиент и PostgreSQL остановлены после проверок.

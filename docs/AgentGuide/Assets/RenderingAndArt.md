# Рендеринг и оформление

Обязательные инструкции для Assets. Область действия, даты, исключения и разрешения исходного Assets/AGENTS.md сохранены.

- Клиент поворачивает длинную ось модели стены по подтверждённому направлению сегмента и берёт ширину и длину из общей геометрии строительства. Нахлёст в 2 см закрывает зазоры от округления координат.
- Каменоломня использует модель `Quarry` из `CombatRenderCatalog`. Ступени выработки, подъёмник и вагонетка входят в один меш с отдельными секциями для окраски.
- Постоянные постройки получают из `CombatRenderCatalog` модели без подставок по имени `StructureKind`. Клиент вписывает их в реплицированную область постройки по обеим горизонтальным осям и поворачивает по подтверждённому углу размещения. В новом выпуске площадка мастерских, башни и святилища составляет 2,4 × 2,4 м, церкви — 4 × 4 м.
- Вертикальный масштаб построек задаёт `ClientPresentationDefinition`. Положение, ширина и длина области опоры задаются симуляцией. Метки уровней в боевом окне проецируются над верхней точкой увеличенной модели.
- На клиенте отрезки от боевой камеры к герою проверяются по повёрнутым габаритам построек, стволов и крон деревьев. На время перекрытия в боевом окне рисуются части модели с полупрозрачными материалами URP и плавной сменой прозрачности. На миникарте в это время видна обычная модель. Варианты материалов деревьев сохраняют текстуры коры и вырезы листвы. На речной карте лес и древесные месторождения рисует `RiverVegetationPresentationSystem`, кольца бесконечных месторождений остаются отдельным эффектом.
- Бесконечные месторождения дерева и камня на речной карте выбирают по реплицированному виду ресурса и флагу `Infinite` собственные меши из `RiverWorldMaterials`. Для дерева это пень с корневой аркой и молодой порослью, для камня — расколотый монолит с голубой жилой. Модели опираются на рельеф и поддерживают тот же полупрозрачный материал при перекрытии героя. Кольца и отметки ∞ рисуются отдельно из состояния месторождения.


### Исходный раздел: 5. Unity lifecycle и ресурсы; строка 131

- `OnValidate` выполняет локальную проверку, без установки пакетов, перестройки сцены и изменения сессии. Не уничтожай общие material/mesh/asset как собственный runtime-экземпляр.


### Исходный раздел: 10. Сериализация и безопасная миграция; строка 188

- В `Presentation` есть шейдеры. Сохраняемый контент не удаляется вместе с архитектурой; проверяй ссылки префабов, основной и recovery-сцен.

Этот раздел не поручает самостоятельно начинать удаление или перенос файлов.

Локальный Windows-стенд без Docker запускается через `backend/scripts/start-windows.ps1`: существующий PostgreSQL проекта, API и выделенный сервер. Launcher использует выбранный ContentRelease и существующие `.runtime`-секреты; не пересоздаёт базу, не пересобирает Unity и не завершает посторонние процессы. Успех требует готовности БД/API и регистрации серверной сборки с текущими версиями контента и протокола.



### Исходный раздел: Скелетные персонажи Shadow Ages; строка 231

- RenderMeshArray в 6.6 содержит хост с подсчётом ссылок. Если System хранит массив между удалением и повторным созданием сущностей, она вызывает Retain сразу после создания и Release при уничтожении; одной C#-копии структуры недостаточно. Иначе удаление последней shared-component ссылки ломает следующий reconnect/FX spawn.

[Карта обратимого переноса](MigrationManifest.json) фиксирует исходные байты и размещение фрагментов. Для восстановления соединить диапазоны StoredStart/StoredLength в порядке SourceStart, предварительно отменив LinkEdits. Исходник должен совпасть по размеру и SHA-256. После будущих правок смещения могут устареть.
